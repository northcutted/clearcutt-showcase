Create the ClearCutt showcase GitHub App

This form creates a private GitHub App, clearcutt-showcase-bot, on your account (northcutted) through GitHub's App manifest flow, with only these repository permissions: Contents read and write, Pull requests read and write, Metadata read; webhook off.

  1. Click Create below, then Create GitHub App on GitHub.
  2. GitHub redirects to the showcase portal with ?code=… in the address bar. Copy that code (it is valid for one hour) and run 
    bringup/bringup.sh app-from-code --owner northcutted --owner-type user --code CODE --apply
    which exchanges it for the App's ID and private key and sets the credentials on the five repositories.
  3. Install the App on the five showcase repositories (the script prints the link).
